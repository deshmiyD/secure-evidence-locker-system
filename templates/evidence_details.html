Integrity Verification Process
  1. Decryption: The encrypted file is retrieved from storage and decrypted using AES encryption.
  2. Hash Computation: SHA-256 hash is recomputed from the decrypted file bytes.
  3. Comparison: The recomputed hash is compared with the stored hash from the database.
  4. Result: If hashes match, integrity is verified. If they differ, tampering is detected.
